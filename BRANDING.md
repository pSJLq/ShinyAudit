## Descriptions (English, ready to paste)

### One-liner (tagline)
> A swarm of on-chain agents that reads the Somnia ledger for you — forensic depth, autonomous, verifiable.

### Short (≤ 160 chars — for cards, app stores, OG)
> ShinyAudit is an agentic on-chain investigator on Somnia. Ask in plain language; a swarm of agents reads the ledger and returns a verifiable verdict.

### Twitter / X bio (≤ 160 chars)
> A swarm. A ledger. A verdict. Agentic on-chain investigator built on Somnia's Agentic L1. Ask anything that lives on-chain — get receipts.

### Medium (hackathon submission blurb)
> **ShinyAudit** turns any on-chain question into an autonomous investigation.
> Ask in plain language — *"audit this casino for backdoors", "who owns this
> wallet", "is this token a honeypot", "where did the treasury go"* — and a
> swarm of agents running natively on **Somnia's Agentic L1** plans the work,
> reads the ledger, and returns a verdict you can verify. Every step is a real
> on-chain agent call with a sealed receipt — no off-chain shortcuts.
>
> Under the hood: 160+ composable on-chain tools spanning contract audit,
> identity resolution (OpenSea / X / ENS / Farcaster / Lens), fund-flow tracing,
> honeypot & rug detection, token-distribution analysis, and bytecode-level
> reverse-engineering of *unverified* contracts. An MCP server exposes the whole
> toolset to any LLM client.

### Long (about / docs intro)
> Most blockchain explorers show you data. ShinyAudit *answers questions.*
>
> It's an agentic investigator built for Somnia's Agentic L1: you describe a
> target in any language, and an orchestrated swarm of on-chain agents decides
> which tools to run, executes them as real Somnia agent transactions, reasons
> over the results across multiple rounds, and composes a forensic dossier —
> verdict first, evidence and citations below.
>
> What makes it different:
> - **100% on-chain & agentic.** Every tool call is a `createRequest` to the
>   Somnia agent platform, finalized by a validator subcommittee, with a public
>   receipt. Nothing is faked off-chain.
> - **Adaptive, not scripted.** A universal toolset (read any view function by
>   signature, recover ABIs from raw bytecode, resolve identities across
>   platforms, score risk, trace funds) lets it tackle questions nobody
>   pre-programmed.
> - **Reverse-engineers the opaque.** Even with no verified source, it
>   disassembles bytecode, recovers the callable surface, reads raw storage
>   slots, and flags dangerous opcodes.
> - **Verifiable by design.** Sealed receipts on `agents.testnet.somnia.network`
>   back every claim.
>
> A swarm. A ledger. A verdict.
